
# mardiahanrissya-web

Personal portfolio website for Mardiah Anrissya, built with HTML/CSS.  
Live Preview: [https://mrdsya10.github.io/mardiahanrissya-web/](https://mrdsya10.github.io/mardiahanrissya-web/)

## How to Publish on GitHub Pages

1. Go to your repository on GitHub
2. Click on **Settings**
3. Scroll down to **Pages**
4. Under "Source", choose branch: `main` and folder: `/ (root)`
5. Click **Save** — your site will be live at:
   ```
   https://mrdsya10.github.io/mardiahanrissya-web/
   ```
